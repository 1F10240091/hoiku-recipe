# ほいくレシピ

保育園の献立表と子どもの食事条件を管理し、登録済みレシピから家庭向けの献立を提案するWebアプリ

**Next.js 16 / React 19 / TypeScript · FastAPI · SQLite（開発）**

---

## 現在の主な機能

- アカウント登録・ログイン
- 子どもの登録、アレルギーと好き嫌いの管理
- 園の献立表のアップロード・Gemini解析
- 登録済みレシピから1〜7日分の夕食を提案
- レシピ検索・投稿・公開設定・お気に入り
- 在庫・買い物リスト
- 投稿レシピの写真（任意）と、写真がない場合のSVGイラスト
- 29品目のアレルゲン候補と関連食材の照合
- 公式レシピ100件を収録（コード上のシード数）

---

## 献立表解析と献立提案は別の仕組み

### 献立表

Gemini APIでPDF/PNG/JPEG/WebPを解析（4MBまで、PDFは最大5ページ）。`GEMINI_API_KEY` が必要で、失敗時の別OCRへの自動切替はありません。

### 夕食提案

AI生成ではなく、登録済みレシピをルールベースで選定。月齢・アレルギー・「除外」設定・在庫を参照します。

---

## 現在の制約

- 「改善優先」は提案ロジックに反映されない
- 園の献立との重複回避は簡易的で、主菜名を中心に判定。食材単位の回避は未対応
- アレルギー判定はレシピ記載の食材名に基づき、安全を保証するものではない
- 投稿レシピは初期状態で非公開
- 本番はPostgreSQL必須。AlembicのDB更新手順があるが、デプロイ完了は未確認
