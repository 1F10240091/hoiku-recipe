## 技術リソース

- **開発環境**: Node.js 20.19以上（Vercelは22.x推奨）/ Python 3.12
- **デザイン・管理**: GitHub / Figma / ESLint / Prettier
- **インフラ**: 開発はSQLite。本番はPostgreSQL必須。Vercel向け設定あり、実デプロイは未確認
- **献立表解析**: Gemini API（`GEMINI_API_KEY` が必要）
- **献立提案**: DB登録済みレシピを選ぶルールベース方式。AIによる新規レシピ生成は行わない
